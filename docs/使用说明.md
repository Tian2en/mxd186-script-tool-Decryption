# 使用说明

## 一、快速开始

双击 `MXD186脚本工具.exe` 打开界面，有两个标签页。

### 单个文件

1. 点击「选择文件…」选一个 `.jse`（或直接把文件拖进窗口）
2. 输出目录留空则输出到 jse 同目录
3. 勾选「解密」和/或「去混淆」
4. 点「开始处理」

### 批量文件夹

1. 选择（或拖入）输入文件夹
2. 输出文件夹留空则自动为 `<输入>_解密去混淆`
3. 勾选「包含子文件夹」「解密」「去混淆」
4. 设置「并发」（默认 8，机器逻辑核数 − 2）
5. 点「开始批量处理」

---

## 二、拖拽规则

| 拖入内容 | 行为 |
|---|---|
| 单个 `.jse` 文件 | 切到「单个文件」页并填入 |
| 一个文件夹 | 切到「批量文件夹」页并填入 |
| 多个文件 | 切到批量页，以其所在目录为输入 |

也可以直接拖到对应的输入框上。

---

## 三、输出命名

统一输出为 `<名称>.js`，批量模式保持原目录结构。

| 勾选情况 | 输出内容 |
|---|---|
| 只「解密」 | 解密结果（仍是混淆代码，服务端可直接加载） |
| 只「去混淆」 | 可读源码 |
| 两个都勾 | 可读源码（解密作为中间步骤，不额外保留） |

---

## 四、异常处理

| 情况 | 处理 |
|---|---|
| 空文件（0 字节） | 记为「跳过」，不算失败，不产出文件 |
| 非法 Base64 / 密文长度非 16 倍数 | 记为「失败」 |
| 单个文件去混淆失败 | 自动回退输出解密结果，保证有产出 |

批量模式下失败清单会写入输出目录的 `_errors.txt`。

---

## 五、命令行模式

适合批处理 / 自动化 / 服务器运维。

```
MXD186脚本工具.exe --cli <输入.jse或文件夹> <输出目录> [选项]
```

| 选项 | 说明 |
|---|---|
| `--rec` | 递归处理子文件夹 |
| `--no-deob` | 只解密，不去混淆 |
| `--workers N` | 并发进程数（默认 8） |
| `--log 文件` | 日志输出路径（默认写到 `<输出目录>\_cli_log.txt`） |

### 示例

```bat
:: 处理单个文件
MXD186脚本工具.exe --cli "D:\脚本\特殊\AI信息菜单.jse" "D:\out"

:: 批量递归处理，10 并发
MXD186脚本工具.exe --cli "D:\Server\脚本" "D:\out" --rec --workers 10

:: 只解密，不去混淆
MXD186脚本工具.exe --cli "D:\Server\脚本" "D:\out" --rec --no-deob
```

### 日志格式

```

DEOB ok=19346 err=0
TOTAL ok=19346 skip=1 err=0 files=19347

```

## 六、常见问题

**Q：首次启动很慢？**
单文件 exe 需要把内置运行时解压到临时目录，约 3–10 秒，属正常现象。

**Q：杀毒软件报毒？**
PyInstaller 打包的 exe 常被误报。可自行从源码构建，或添加信任。

**Q：提示「去混淆不可用」？**
说明缺少 `node.exe` 或 `deob_bundle.js`。从源码运行时会这样，
把 `node.exe` 放到项目根目录即可。

**Q：想换密钥？**
改 `src/app.py` 里的 `AES_KEY_HEX`（16 字节十六进制）。

**Q：处理完怎么部署回服务端？**
把输出的 `.js` 覆盖到服务端脚本目录，并删除对应的 `.jse`
（服务端加载规则：同名 `.jse` 存在时优先解密 `.jse`，否则读明文 `.js`）。
